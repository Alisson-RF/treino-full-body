# Treino Full Body — versão instalável (PWA)

Esta pasta contém uma versão PWA do seu HTML original. Os treinos e a lógica da aplicação foram mantidos; foram acrescentados o manifesto, ícones e cache offline.

## Como instalar no Android

1. Publique **todo o conteúdo desta pasta** em um endereço HTTPS. Uma opção gratuita é o GitHub Pages.
2. No Android, abra o endereço publicado no Google Chrome.
3. Abra o menu ⋮ e escolha **Instalar app** ou **Adicionar à tela inicial**.
4. Confirme. O Treino Full Body aparecerá como um aplicativo e poderá abrir em tela cheia.

## Publicar gratuitamente com GitHub Pages

1. Entre em https://github.com e crie um repositório público, por exemplo `treino-full-body`.
2. Envie todos os arquivos desta pasta para a raiz do repositório (incluindo `index.html`, `manifest.webmanifest`, `sw.js` e a pasta `icons`).
3. No repositório, vá em **Settings → Pages**.
4. Em **Build and deployment**, escolha **Deploy from a branch**, selecione `main` e `/ (root)`, e salve.
5. Aguarde a publicação. O GitHub mostrará um endereço terminado em `github.io`.
6. Abra esse endereço no Chrome do Android e instale.

## Observações

- A instalação PWA precisa de endereço HTTPS; abrir o arquivo HTML diretamente do armazenamento do celular não habilita a instalação.
- O cache permite abrir a aplicação offline depois do primeiro acesso bem-sucedido.
- Os vídeos, pesquisas de GIF e outros links externos continuam dependendo de internet.
- Os dados continuam sendo armazenados no próprio navegador/dispositivo, conforme o HTML original. Limpar os dados do navegador pode apagá-los.
- Esta versão foi preparada a partir do HTML fornecido, mas não foi testada em uma publicação HTTPS real neste ambiente.
